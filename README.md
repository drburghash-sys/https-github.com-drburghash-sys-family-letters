# تحدي الحروف

لعبة عائلية جماعية مستوحاة من ألعاب الحروف والمسارات السداسية.

- فريق أخضر: هدفه تكوين مسار من أعلى اللوحة إلى أسفلها.
- فريق أحمر: هدفه تكوين مسار من اليمين إلى اليسار.
- مضيف يتحكم بالأسئلة وإسناد الخلايا.
- شاشة عرض متزامنة عبر Firebase.
- مصممة للوضع الأفقي على الجوال والتلفزيون.
- أيقونة وWeb App Manifest مدمجان.
